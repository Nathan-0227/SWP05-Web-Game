# SWP05 網頁小遊戲：貪食蛇

使用 HTML、CSS、JavaScript 與 LocalStorage 製作的貪食蛇，不需要安裝任何東西，也沒有使用外部函式庫。

## 如何開啟

直接雙擊 `index.html`，用瀏覽器開啟即可。建議使用 Chrome。

## 遊戲規則

- 控制蛇吃掉紅色食物，每吃一個加 1 分。
- 吃滿 **20 個** 就 **過關**。
- 撞到牆壁或撞到自己就 **失敗**。
- 畫面上方會即時顯示分數和經過的時間。

## 操作方式

| 按鍵 | 功能 |
| --- | --- |
| `↑` `↓` `←` `→` 或 `W` `A` `S` `D` | 控制方向 |
| `空白鍵` | 開始／暫停／繼續 |
| `R` | 重新開始 |

畫面下方也有「開始」和「重新開始」按鈕；結算畫面有「再玩一次」按鈕。

- 不能直接往反方向回頭。
- 快速連按兩個方向會依序執行，不會漏掉。
- 切換分頁或視窗時，遊戲會自動暫停，計時也會停止。

## 難度

| 難度 | 速度 |
| --- | --- |
| 簡單 | 每 150 毫秒走一格 |
| 普通 | 每 100 毫秒走一格 |
| 困難 | 每 70 毫秒走一格 |

三種難度的過關目標都是 20 個，只差在速度。遊戲進行中（含暫停）不能切換難度。

## 遊戲結果

遊戲結束時會顯示：

- 過關（🎉）或失敗（💀），以及失敗原因（撞牆／撞到自己）
- 這局的分數與時間
- 這個難度的最佳紀錄
- 打破紀錄時顯示「新紀錄！」

## 音效

音效用 Web Audio API 即時產生（吃到食物、過關、失敗各一種），不使用音檔。側邊欄可以切換靜音。

## LocalStorage

| Key | 內容 |
| --- | --- |
| `swp05-snake.records` | 每個難度的最高分（`bestScore`）與最快過關時間（`bestTime`，毫秒） |
| `swp05-snake.settings` | 上次選擇的難度與靜音設定 |

- 重新整理頁面後，紀錄和設定都會保留。
- 「清除目前難度紀錄」按鈕會在確認後，清除目前所選難度的紀錄。

## 檔案結構

```
index.html   頁面結構
style.css    樣式
script.js    遊戲邏輯、繪圖、LocalStorage
README.md    說明文件
```

## 備註

- 部分瀏覽器規定使用者操作過頁面後才能播放聲音，所以音效會在第一次按下「開始」後啟用。
- 以 `file://` 開啟時，各瀏覽器對 LocalStorage 的處理略有不同；Chrome 可以正常保存紀錄。
